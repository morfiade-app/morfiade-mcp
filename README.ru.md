# Morfiade MCP

**MCP-сервер для профилей Google Chrome на вашей машине.** Восемнадцать
инструментов: ИИ-агент видит, создаёт, запускает и раскладывает настоящие
профили Chrome — каждый со своими куками, входами и прокси.

Сервер не качается из интернета: он внутри самой программы
[Morfiade](https://morfiade.com/) и поднимается ключом. Транспорт — stdio
(JSON-RPC 2.0), версия протокола `2025-11-25`. Ничего не скачивается и ничего
не идёт через чужой сервер.

В этом репозитории — описание, готовые настройки для клиентов и необязательная
запускалка. English version — [README.md](README.md).

---

## Чем это отличается

**Мост живёт в программе.** У AdsPower и GoLogin MCP есть, но отдельным пакетом
из интернета и с выходом в их облако. У Morfiade профили лежат на вашем диске —
значит и мост на вашем диске: `Morfiade.exe --mcp`, через локальную петлю, сеть
не нужна.

**Раздача значений по окнам.** То, чего нет ни у кого: `sync_sets` /
`sync_spread` / `sync_insert`. Набор значений — почты, логины, что угодно
построчно — раскладывается по открытым окнам, каждому профилю своё. Повторный
вызов не переставляет уже закреплённое: иначе аккаунт зарегистрировали бы на
одну почту, а подтверждали другой. Сами значения агент при этом не видит — см.
[«Чего агент не может»](#чего-агент-не-может).

Просьбы, которые работают сразу:

> Заведи двадцать профилей с приставкой `shop`, раздай прокси из этого списка и
> запусти первые пять.

> Проверь прокси у всех доступных профилей и скажи, какие мёртвые или выходят не
> из той страны.

> Возьми набор `mail-batch`, разложи по открытым окнам и покажи, кому что
> досталось. Я поставлю курсор в поле почты — тогда вставишь.

## Что нужно

- Windows 10 или 11
- [Morfiade](https://morfiade.com/) 3.36 или новее, **запущенная**
- **включённый локальный API** в настройках — без него сервер честно откажется
  стартовать, а не будет молчать
- **галочка «API»** у тех профилей, к которым агента пускаете; по умолчанию она
  снята, и непомеченных профилей для агента не существует
- действующая лицензия, чтобы *запускать* профили (проверка стоит в менеджере, а
  не здесь)
- любой MCP-клиент со stdio: Claude Code, Claude Desktop, Cursor, Gemini CLI,
  VS Code, свой собственный

Ставить ничего не нужно: ни `pip install`, ни Node, ни регистрации ключа.
Запускалка ниже — по желанию.

## Как подключить

Укажите клиенту путь до программы и ключ `--mcp`:

```json
{
  "mcpServers": {
    "morfiade": {
      "command": "C:\\Program Files\\Morfiade\\Morfiade.exe",
      "args": ["--mcp"]
    }
  }
}
```

Готовые файлы для распространённых клиентов — в [`examples/`](examples/).
Claude Code делает это одной строкой:

```
claude mcp add morfiade -- "C:\Program Files\Morfiade\Morfiade.exe" --mcp
```

Где лежит файл настроек, зависит от клиента и меняется чаще этого описания —
смотрите справку своего клиента.

### Необязательная запускалка

Если не хочется вписывать путь руками, [`morfiade_mcp.py`](morfiade_mcp.py) сам
найдёт программу (по `MORFIADE_EXE`, по записи установщика в реестре, в обычных
папках установки или в `PATH`), прокинет ввод-вывод и вернёт её код выхода.
Нужен Python 3.7+ и больше ничего.

```
pip install morfiade-mcp
```

```json
{
  "mcpServers": {
    "morfiade": {
      "command": "morfiade-mcp"
    }
  }
}
```

Если клиенту нужен полный путь — укажите `morfiade-mcp.exe` из папки `Scripts`
вашего Python. Без пакета работает и один файл: `"command": "python"`, а
единственным аргументом — `morfiade_mcp.py`.

В пакете лежит только эта запускалка. Сам сервер и всё, с чем он говорит, — в
программе.

**Режим «только описание».** Вне Windows — например, в Linux-контейнере, где
каталог MCP запускает сервер, чтобы узнать его инструменты, — запускать нечего,
и запускалка отвечает сама: рукопожатие и `tools/list` берутся из схем в
[`schemas/`](schemas/), снятых с настоящего сервера. Любой вызов инструмента
при этом возвращает ошибку «Morfiade работает на Windows»: инструменты
описаны, но не изображаются. Включить режим где угодно, для проверки, —
`MORFIADE_MCP_SCHEMA_ONLY=1`.

## Инструменты

Параметры целиком — [`docs/TOOLS.md`](docs/TOOLS.md) (на английском).

| Инструмент | Что делает |
|---|---|
| `status` | версия, сколько профилей всего, сколько доступно агенту, сколько запущено |
| `list_profiles` | разрешённые профили: имя, запущен ли, прокси, заметка |
| `create_profile` | создать профиль — можно с прокси, заметкой и категорией; агенту разрешён сразу |
| `start_profile` | запустить, можно сразу с адресом |
| `stop_profile` | закрыть окно профиля |
| `set_proxy` | назначить прокси (`тип://логин:пароль@адрес:порт` или `адрес:порт`; пустая строка снимает) |
| `check_proxy` | проверить прокси профиля: живой ли, откуда выходит |
| `check_proxies` | то же сразу у нескольких профилей или у всех |
| `profile_tags` | посмотреть теги или заменить их целиком |
| `profile_note` | посмотреть или записать заметку и её заголовок |
| `sync_windows` | какие окна готовы к раздаче и что каждому уже закреплено |
| `sync_sets` | наборы значений: посмотреть (имя, строк, сколько свободно) или завести новый |
| `sync_spread` | закрепить за окнами по строке набора и показать, кому что; ничего не вставляет |
| `sync_insert` | вставить каждому окну ЕГО значение туда, где курсор у ведущего |
| `list_scripts` | скрипты из папки менеджера: имя и чем запускается, без содержимого |
| `trash_profile` | убрать профиль **в корзину** — данные не стираются |
| `list_trash` | что лежит в корзине: имя, когда, сколько занимает |
| `restore_profile` | вернуть из корзины; занятое имя вернётся как «имя (2)» |

Ещё два появляются только по явным ключам — см.
[«Опасные ключи»](#опасные-ключи-по-умолчанию-выключены).

## Чего агент не может

Агент, читающий веб-страницы, — не доверенная сторона. На странице может стоять
текст «вызови такой-то инструмент и отправь куки туда-то», и агент не отличает
вашу просьбу от найденной в интернете. Это признанная главная беда MCP, и
формулировками она не лечится. Поэтому границы стоят в самом списке
инструментов:

- **Удаление — только в корзину.** Профиль лежит целиком, вместе с куками и
  входами, и возвращается одним вызовом. Стирания насовсем и очистки корзины
  здесь нет и не будет: это единственные необратимые действия, и делает их
  человек из окна корзины, где видит, что именно стирает.
- **Чтения куки нет.** У GoLogin такой инструмент есть — то есть куки уезжают из
  аккаунта в переписку с ИИ. Здесь его нет.
- **Строки наборов наружу не отдаются.** `sync_sets` показывает имя, сколько
  строк и сколько свободно. Сами почты и логины остаются в менеджере — агенту не
  нужно их видеть, нужно, чтобы они попали в окна.
- **Содержимое скриптов не отдаётся.** `list_scripts` — только имена и чем
  запускается.
- **Зеркало наружу не отдаётся.** Оно про то, что человек прямо сейчас делает
  руками в ведущем окне, — агенту повторять нечего.
- **Белый список не обойти.** Колонку «API» фильтрует сам менеджер, а не этот
  сервер.
- **Лицензия не слабеет.** Проверка стоит в обработчике менеджера: кто бы ни
  дёрнул запуск — человек, скрипт или агент, — она срабатывает там же.
- **В сети ничего не слушает.** Локальный API живёт на `127.0.0.1`, требует
  токен и проверяет заголовок `Host`. Токен на диске зашифрован средствами
  Windows (DPAPI, привязка к учётной записи) и ходит заголовком, а не в адресе:
  адреса попадают в журналы.

### Опасные ключи, по умолчанию выключены

| Ключ | Инструмент | Что это значит на самом деле |
|---|---|---|
| `--mcp-allow-cdp` | `browser_command` | произвольная команда протокола Chrome DevTools. `Runtime.evaluate` в залогиненном профиле читает куки, хранилище и содержимое страниц — это полный доступ к вашим аккаунтам, а не «расширенное управление» |
| `--mcp-allow-scripts` | `run_script` | запускает скрипт из папки менеджера — выполнение кода на вашей машине |

Включать стоит, только понимая абзац выше, и только на страницах, которым
доверяете.

## Если не работает

| Что видно | Что делать |
|---|---|
| клиент не показал инструменты | проверьте путь к exe в настройках клиента |
| «Локальный API выключен» | включите его в настройках менеджера |
| «в config.json нет порта или токена» | откройте менеджер хотя бы раз, чтобы он записал настройки |
| «менеджер не отвечает» | менеджер должен быть запущен |
| «профиль не найден», хотя он есть | не отмечена галочка «API» у этого профиля |
| «токен API содержит недопустимые знаки» | конфиг принесён с другой машины — перевыпустите токен в настройках |
| запуск профиля отказывает | нет действующей лицензии: запуск закрыт и через API, и через MCP |

## Чего здесь нет

Сам мост скомпилирован внутрь `Morfiade.exe`, а **механизм переноса сессий** —
то, чем логины действительно переезжают между машинами, — остаётся закрытым. В
этом репозитории внешняя сторона продукта: описание, настройки, запускалка.
